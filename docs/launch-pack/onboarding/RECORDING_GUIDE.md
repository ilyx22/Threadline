# Recording guide

> Status: drafted; owner review pending. Client-facing. Pages: **Recording → Your setup** and **Recording → Recording Room**. Adapted from the Recording Readiness Install V2 draft.

## 1. Set up once (Your setup)

Send Threadline:

- **Setup photo:** a wide shot of the room, and anything else that helps.
- **Test clip:** 30 to 60 seconds in the position you'll film from. Send it as a link; Threadline only stores the link.
- **What you record on:** camera or phone, microphone, lights and tripod. Use what you already own.
- **The room:** where you sit, what's behind you, what the light is doing, and whether it's quiet.
- **Formats you need:**
  - **Vertical short-form (9:16)** is the default for every engagement.
  - **Horizontal long-form (16:9)** is only for an agreed long-form pilot.

Then press **Send for review**. Threadline checks:

- audio;
- light;
- framing;
- background;
- focus and stability;
- repeatability (can you set it up alone next time?);
- format.

We tell you the single most important change. Recording setup problems show at the top of **This week** until they're fixed.

**Upgrade in this order:**

1. Clean, close audio.
2. Controlled, flattering light.
3. Stable framing and background.
4. Only then a better camera, and only if the phone is the real limit.

Buying equipment is your choice and isn't included.

## 2. Before each session: pre-flight (about two minutes)

- [ ] Lens clean; camera or phone stable.
- [ ] Right orientation for the format.
- [ ] Microphone connected; play back a test.
- [ ] Light and background match your approved setup.
- [ ] Storage, battery and power available.
- [ ] Do a 10-second test clip: check the sound and focus.
- [ ] Do Not Disturb on.
- [ ] Record the takes in the order the Recording Room shows.

## 3. Recording (Recording Room)

- Approved scripts appear here, with a **Teleprompter**:
  - adjustable speed and text size;
  - Space to pause;
  - arrow keys to move between scripts.
- If the queue is empty, the hold-up is upstream (scripting or approvals), not with you.
- Delivery tips:
  - speak to one person;
  - do several takes rather than forcing one perfect take;
  - pause cleanly instead of filling gaps;
  - say the working title at the start of a take if it helps the editor.
- After recording, mark the piece as recorded and use **Upload raw footage**. You can also add a link if the file lives in Drive or Dropbox.

## 4. Troubleshooting

| Problem | What to do |
| --- | --- |
| Echo or muffled sound | Move the microphone closer to you. Add something soft to the room (rug, curtains). |
| Flicker under indoor lights (UK) | Record at 25 fps with a 1/50 shutter if your camera allows it. |
| Face too dark, or blown out | Face the window rather than sitting with it behind you. Fix white balance so it doesn't drift. |
| A large upload is slow or fails | Files over 10 MB upload in parts with a progress bar. The Library accepts video, audio or image files up to 512 MB. If it fails, retry, or add a link to the file instead. |
| A file shows "Processing", "Processing queued" or "Processing failed" | Transcoding and transcripts only run where Threadline has turned on file processing. If it fails, tell us through **Help**. |
| A file is marked quarantined | The scanner flagged it (only where scanning is on). Send a clean copy. |
