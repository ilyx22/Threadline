THIS ISSUE

Every piece is a test. Read it honestly.

Before a piece goes out, write down what you expect it to do and why. After it has had time to be read, compare what happened with what you expected. The useful part is not the score; it is the reason.

We run the same five steps every time: score the piece against a stated rubric, explain which parts carried it, diagnose whether the idea, the packaging or the distribution was the weak link, prescribe one change, and retest on the same root idea.

The loop: score, explain, diagnose, prescribe, retest. Expected against actual sits in the middle.
