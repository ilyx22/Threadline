# SOP 02 - Daily Acquisition Operating SOP (V14.2 Course-Authority)

## Trigger
Launch Gate passed, SOP 00 V14 validation gate passed, active niche/problem hypothesis selected, acquisition capacity available.

## Objective
Produce the mathematically required number of qualified buyer conversations to hit the 90-day client target, while learning the niche/message/channel through controlled reps.

## 1. Reverse-engineer the target
Required first touches = target wins / (booking rate x show rate x qualification rate x close rate).
Required first touches/day = required first touches / remaining acquisition workdays. Round UP.

Until Threadline has data, use deliberately conservative, clearly labelled assumptions. Never borrow another creator's percentages as Threadline benchmarks. The current illustrative model (2 wins, 2% booking, 75% show, 75% qualified, 15% close, 60 workdays) produces ~1,185 first touches or ~20/day, but this is an example only.

Every Friday freeze the raw counts, replace assumptions with real data where the denominator is meaningful, recalculate the remaining quota and diagnose the first broken conversion. Keep early assumptions visible beside tiny-sample actuals so one win/no-show does not create false precision.

## 2. Current launch acquisition architecture
- Primary delivery hypothesis: qualified cold email.
- LinkedIn: lead sourcing, context, credibility and supportive follow-up; not a second independent machine.
- A-fit: 1-2 personalised Loom/diagnoses when economics justify the effort.
- Warm/referral: tracked separately.
- Own content: inbound/trust layer after required revenue actions.

## 3. Daily sequence
1. Open scoreboard. Handle live replies and overdue follow-ups first.
2. Complete due follow-ups. Stop on explicit no/opt-out.
3. Source enough A/B-fit prospects to meet today's calculated first-touch requirement.
4. Verify company, decision-maker, economics, content symptom and one specific observation.
5. Send current versioned stimulus through the current primary delivery mechanism.
6. Use LinkedIn context/support only where it improves relevance or follow-up.
7. Create personalised Looms only for exceptional A-fit accounts.
8. Book qualified conversations into the diagnosis call.
9. Log source, message version, date, fit, reply class, next action and hours.
10. Only after required revenue actions: publish/prepare Threadline's own content.

## 4. Weekly acquisition-control review
1. Freeze raw counts for the week.
2. Recalculate booking, show, qualification and close rates.
3. Recalculate remaining touches and next week's daily quota.
4. Find first broken conversion: reach/contact -> reply -> positive -> booking -> show -> qualified -> offer -> close -> cash -> delivery quality.
5. Change one meaningful variable at a time and preserve the previous version for comparison.
6. Keep warm/referral, cold outbound and inbound rates separate when volume permits.

## 5. Script-change rule
Do not wholesale rewrite because a few calls/messages feel uncomfortable. Preserve versions and accumulate a meaningful sample. For sales-script changes, target roughly 30 qualified calls before emotional overhaul unless a fatal flaw is obvious.

## Definition of done for day
Due replies/follow-ups handled + calculated qualified first-touch target hit + CRM/scoreboard current.

## NEXT SOP
Call booked -> SOP 03. Win -> SOP 04. Otherwise repeat SOP 02.
