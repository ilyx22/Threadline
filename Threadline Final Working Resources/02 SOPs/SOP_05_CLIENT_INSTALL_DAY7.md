# SOP 05 - Client Installation / Day-7 Win

## Trigger
Signed/paid client has kickoff scheduled and workspace exists.

## Objective
Within 7 days create visible strategic progress and start the first production cycle.

## Day 0-1 - Understand + baseline
- Run Brand Brain: business, ICP, offer, economics, proof, voice, worldview, content, sales process, claims/banned claims.
- Capture current content output, founder hours, cycle time, available pipeline/commercial signals.
- Confirm client responsibilities and approval/recording cadence.
- Start Recording Readiness Install: room photos, gear, 30-60 sec test clip.

## Day 1-3 - Research + diagnosis
- Collect market/customer/competitor evidence with provenance.
- Separate raw evidence from candidate signal.
- Draft primary constraint hypothesis + alternatives + confidence + commercial consequence.
- Promote only evidence-backed signals.
- Fix Recording Readiness largest constraint; obtain new test clip if required.

## Day 3 - Strategy
- Define 3-5 content pillars/messages.
- Select first 3 strategic tests/angles.
- Define 30-day content hypothesis and relevant CTA/conversion path.

## Day 4 - Recording-ready batch
- Prepare first 6-8 scripts/outlines.
- Fact/claim check.
- Voice QA.
- Prioritise recording queue.
- Mark long-form YouTube as PILOT/CUSTOM unless explicitly sold.

## Day 5-7 - Record + production begins
- Client records using approved setup.
- Check footage quickly while re-recording is still easy.
- Hand clean assets/instructions to editor.
- Internal QA before client approval.
- First assets enter edit/approval/scheduling.

## Day-7 client summary
Send/show:
- what we learned;
- current constraint hypothesis + evidence;
- what we're testing first;
- what has been scripted/recorded/entered production;
- what Threadline is working on now;
- next client action.

## Blocker rule
If client delays access/recording/approval, record blocker, date and impact. Do not fake milestone completion.

## Definition of done
Brand Brain complete + baseline captured + diagnosis exists + Recording Readiness signed off + first strategy/tests approved + first batch recording-ready + production started.
