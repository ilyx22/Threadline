# THREADLINE ACQUISITION REVERSE-ENGINEERING CONTROL LOOP (V14.2)

## Purpose
Turn acquisition from "did I work hard today?" into a measurable operating system. Daily acquisition volume is calculated from the client target and current funnel conversion rates. The quota is never a motivational number.

## Core equation
`required first touches = target wins / (booking rate x show rate x qualification rate x close rate)`

`required first touches per acquisition day = required first touches / remaining acquisition workdays`

Use decimal rates in the calculation (2% = 0.02). Round the daily requirement UP.

## Funnel
Qualified first touches -> replies -> positive replies -> bookings -> shows -> qualified calls -> offers -> wins -> cash collected.

The four rates in the core equation are the minimum planning variables. The intermediate rates are diagnostic variables used to identify the first broken conversion.

## Launch rule
Before sufficient Threadline data exists, use deliberately conservative planning assumptions. Label every assumption. Do not present borrowed creator/mentor percentages as benchmarks or truth.

Illustrative example only:
- target wins: 2
- booking rate: 2%
- show rate: 75%
- qualification rate: 75%
- close rate: 15%
- remaining acquisition days: 60

This implies about 1,185 qualified first touches, or 20/day after rounding up. This example is not a target. Real Threadline data replaces it.

## Friday recalculation
Every Friday:
1. Freeze the week's raw counts before changing anything.
2. Recalculate booking, show, qualification and close rates.
3. Recalculate the remaining touches required to hit the target.
4. Find the first weak conversion in the funnel.
5. Change ONE meaningful variable aimed at that bottleneck.
6. Preserve the prior message/channel/version so the comparison remains legible.
7. Set next week's daily quota from the new math.

## Early-data discipline
When denominators are tiny, do not let one win or one no-show wildly change the plan. Keep the original conservative planning assumptions visible beside actuals until the sample is meaningful. The purpose is direction, not false precision.

## Daily founder scoreboard
A normal acquisition day is complete only when:
- live replies and overdue follow-ups are handled;
- the calculated number of qualified first touches is completed;
- every touch/outcome is logged;
- the next action is scheduled;
- optional building/content happens only after required revenue actions.

## Channel rule
Calculate performance by source/channel separately when volume permits. Do not blend warm referrals, cold outbound and inbound content into one rate because their economics differ.

## Decision rule
If the daily quota looks absurdly high, do not automatically "work harder." Diagnose which input is making the math bad: niche quality, reachability, message, booking rate, show rate, qualification, sales, pricing, proof, or fulfilment capacity. Better economics should reduce required activity.

## Non-negotiables
- Do not borrow someone else's 35% close rate or 10% booking rate as if Threadline owns it.
- Do not lower the quota because outreach feels uncomfortable.
- Do not increase volume by contacting C-fit prospects.
- Do not change niche + offer + message + channel at the same time.
- Do not use software building as a substitute for the calculated external input.

## North-star operating question
At the end of each acquisition day ask: **Did we hit the mathematically required qualified input, and what does the funnel now tell us?**
